# Hola 👋, soy Patricio

Soy un estudiante avanzado de **Ciencia Política (UNSAM)** aprendiendo a usar **Python** para construir puentes entre la investigación social, el análisis normativo y la ciencia de datos. Me interesa automatizar la recolección de información pública y extraer valor de datos no estructurados para entender procesos institucionales y regulaciones.

### 🛠️ Lo que vengo haciendo
- **Civic Tech & Scraping:** Desarrollé herramientas para monitorear publicaciones oficiales y noticias automatizando flujos de trabajo.
- **Análisis de Datos & Text Mining:** Busco aplicar técnicas cuantitativas a textos legales y normativas (actualmente trabajando en el análisis de regulaciones de telecomunicaciones en Argentina).
- **Automatización de Procesos:** Estoy explorando con el diseño de bots e integraciones (APIs, LLMs, Telegram, GitHub Actions) para optimizar el procesamiento de información.

### 💻 Mis herramientas (Stack Tecnológico)
- **Lenguajes:** Python y SQL
- **Análisis y Scraping:** Pandas, BeautifulSoup, Requests, PyPDF, Jupyter Notebooks
- **Automatización y Flujos:** GitHub Actions, integraciones con APIs (LLMs, Telegram)

### 🚀 Mis proyectos

#### 🏛️ [Monitor del Boletín Oficial](https://github.com/phpm99/monitor-boletin-oficial-ar)
Una herramienta open-source desarrollada en Python (BeautifulSoup, Pandas) para rastrear y estructurar nombramientos de funcionarios públicos en Argentina a partir del Boletín Oficial. Tengo intención de que permita mayor configuración al usuario de qué es lo que le interesa monitorear a él especificamente.

#### 📰 [Agente-PatoGeno](https://github.com/phpm99/Agente-PatoGeno)
Un bot automatizado de monitoreo de noticias. Utiliza flujos de GitHub Actions (`cron`), parseo de feeds RSS y APIs de LLMs para evaluar la relevancia de los artículos, enviando resúmenes diarios directamente vía Telegram. Surgió con la idea de explorar la utilidad de la IA incorporada a herramientas.

#### 📊 Minería de Textos sobre Normativas (Proyecto de Tesis)
Análisis cuantitativo de regulaciones de telecomunicaciones a través de las distintas administraciones presidenciales argentinas, procesando textos legales complejos para extraer patrones de política pública.
